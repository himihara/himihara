## 得意分野

Web開発を専門とし、フロントエンドからバックエンドまで、領域を横断したフルスタックな開発を得意としています。

単に機能を実装するだけでなく、ステークホルダーと丁寧にコミュニケーションを取り、目的や認識をすり合わせながら、既存システムやサービスの構成を理解し、課題の整理と改善につなげることを大切にしています。

- フロントエンド・バックエンド開発
- Webサービス、Webメディアの機能開発
- 既存システムの調査・改修
- API・外部サービスとの連携
- AWSを利用したクラウド環境での開発
- AIを活用したツール開発
